Compatibility context

The current JSON interface is strict and is distinct from the original Fortran YSpec's line-counted parameter files. Other documented differences include controlled integration steps; boundary-side behavior; responses in fluid and core receiver regions; corrections using receiver gravity and the potential-flux term; and allowed degrees above 1827. Read the source revision's Differences from the Fortran YSpec section before comparing old workflows.

Historical DSpecM1D comparison material attributes YSpecpp to 84be5a6cbe442324c164e5193a66b0911fca5860. That historical comparison does not describe this later code basis and is not replaced by current test coverage. Preserve its attribution when updating comparison material.
