Python interface

The Python package compiles its extension from the checked-out source. It provides calculation objects, structured arrays and plotting tools.

Install from this source tree

From the repository root, create an isolated environment and install the optional plot dependencies along with the editable package. Use the same source revision as the manual notice; there is no released wheel availability claim in this guide. On Ubuntu 24.04, first install the Python prerequisites.

python3 -m venv build/python-venv
. build/python-venv/bin/activate
python -m pip install --upgrade pip
CMAKE_BUILD_PARALLEL_LEVEL=2 OMP_NUM_THREADS=2 python -m pip install -e '.[plot]'

This builds YSpecpp in place with Python 3.12 or later, pocketfft, and NetCDF and standalone C++ programs disabled. The plot extra adds Matplotlib and planetmodel's plotting, map and NetCDF readers. See the exact source metadata and install notes in the Python package README at this source revision.

Run the Bolivia comparison

The downloadable script uses PREM, one source, one receiver and the published geocentric coordinates, with latitude_correction=False to preserve their spherical geometry. It computes degrees 0–300, frequencies 1.5–21 mHz and a 300-minute record sampled every second. From the repository root:

OMP_NUM_THREADS=2 python docs/site/examples/python-small-calculation.py

The returned NumPy array has shape (1, 1, 3, 18001) in source, receiver, component, sample order; components are Z, N and E, and the samples span 0–18,000 s. The printed vertical peak is in metres. This is the full Bolivia comparison workflow, not a short execution check. Its 300-to-600-minute waveform comparison still exceeds the 1% duration target; see the first-seismogram guide for the measured differences and limits.

With the default corrected calculation, use figure = model.figure(calculation.rotation_rate_rad_s, calculation.latitude_correction) for geographic great-circle and radial/transverse direction helpers, and pass that figure explicitly. Model-less helpers use spherical/geocentric coordinates; they do not assume an Earth model. Setting latitude_correction=False treats input latitudes as geocentric.

Download the runnable Python example. The Python functions and classes are documented in the Python package source; the generated API reference covers the public C++ headers.

Choose the interface for the task

Use yspec for seismograms, yspec-snapshot for snapshot grids, and yspec-kernels for the restricted one-source/one-receiver cross-correlation traveltime workflow. The Python API provides richer object-level access, including strain and kernel results. The Python packaging build does not install those three C++ command-line programs; the standard CMake build does. See JSON input files and the kernel workflow for their boundaries.
