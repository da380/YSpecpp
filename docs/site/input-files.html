Input files

Both programs read strict JSON. The input names units where they differ from the high-level SI C++ interface; unknown or misspelled members are errors.

JSON lengths are minutes and sample steps seconds. Depths use kilometres. Source and receiver positions are geographic degrees. Moment-tensor components are N m and force components N in local spherical coordinates (r up, θ south, φ east). All six moment-tensor members are required when the tensor is supplied; force components default to zero.

yspec: seismogram outputs and receivers

output is required and accepts prefix, optional quantity (displacement, velocity, acceleration; defaults to displacement) and optional potential_and_tilt_corrections (false by default). Corrections apply to acceleration. receivers is one receiver group or a non-empty array of groups; each has one or more depth_km values and exactly one of locations or profile. A location is [latitude, longitude]. Profiles use either from + to, or from + azimuth_deg + a two-value distances_deg; both forms require a positive count. A group may name one SAC pole-zero instrument file.

Model, instrument and output-prefix paths resolve relative to the JSON file. Output directories are not created automatically: use a fresh existing run directory. Receiver order is group order, then each group's depth order, with all locations at each depth.

yspec-snapshot: snapshot grid

The snapshot form replaces receivers with snapshots. Its output accepts only prefix and optional quantity (displacement, velocity or acceleration; defaults to displacement). Snapshot members are times_s, depths_km, distances_deg and azimuths_deg. Each accepts a number, a non-empty array, or an inclusive {"min": ..., "max": ..., "count": ...} range. Times must be within the record, depths non-negative, and distances 0..180°.

The downloadable small snapshot fixture exercises that schema with one source, one time, one depth, two distances and two azimuths.
