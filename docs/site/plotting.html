Examples

Plotting results

The optional Python plotting tools read a run's input file and generated output files. They do not change the calculation.

{{REVISION_NOTICE}}

Plot trace components

Install the source package with the plot extra, then run a seismogram using the first-run fixture. From the repository root, save Z, radial and transverse components for receiver 1:

MPLBACKEND=Agg OMP_NUM_THREADS=2 build/python-venv/bin/yspec-plot traces build/first-seismogram/input.json \
  --receivers 1 --components ZRT -o build/first-seismogram/traces.png

Inspect radial kernels and sampled sections

Run the bounded input from the kernel guide first. The plot subcommands accept the kernel input JSON and select a named measurement. For a radial kernel and an along/across section:

MPLBACKEND=Agg OMP_NUM_THREADS=2 build/python-venv/bin/yspec-plot kernels build/kernel-small/input.json \
  --measurement S --deepest 1500 -o build/kernel-small/radial.png
MPLBACKEND=Agg OMP_NUM_THREADS=2 build/python-venv/bin/yspec-plot banana build/kernel-small/input.json \
  --measurement S --parameter vs -o build/kernel-small/section.png

Other plot commands

yspec-plot --help lists traces, record sections, comparisons between runs, snapshots, radial kernels, volume kernels, path sections (banana), and a multi-measurement gallery. Without -o, a plot opens interactively. volume reads a C++-generated NetCDF kernel model; it does not enable volume generation in the Python package build. See the output formats for file roles and units.
